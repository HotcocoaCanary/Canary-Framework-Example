# 安全策略 / Security Policy

本仓库是 [Canary Framework](https://github.com/HotcocoaCanary/Canary-Framework) 的示例，不发布
软件包。`.env.example` 中的值均为本地占位，不要把真实凭据提交到仓库。

This repository holds examples for Canary Framework and publishes no packages. Values in
`.env.example` are local placeholders; never commit real credentials.

## 报告漏洞 / Reporting a Vulnerability

请**不要**创建公开 Issue。/ Please do **not** open a public issue.

- 框架本身的漏洞：按[主仓库的安全策略](https://github.com/HotcocoaCanary/Canary-Framework/blob/main/SECURITY.md)报告。
  Vulnerabilities in the framework: follow the main repository's security policy.
- 示例代码中的问题：通过[私有安全报告](https://github.com/HotcocoaCanary/Canary-Framework-Example/security/advisories/new)
  或邮件 **Cacao.Canary@outlook.com** 报告。
  Issues in the example code: report via a private security advisory or by email.
